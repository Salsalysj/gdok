# 내 캐릭터 시뮬레이션 vs 상급재련 시뮬레이션 — 상재 보조재료 가치 분석 차이

두 페이지 모두 **동일한 상급재련 JSON 시뮬레이션 데이터**를 쓰고, **마진 분석** 공식(noAux → enhanced만 → 선조+강화 → 전부 사용)도 같습니다.  
**값이 다르게 나오는 이유**는 **재료 단가·실링·보조재료 시세**를 **서로 다른 소스**로 쓰기 때문입니다.

---

## 1. 재료 단가 소스 (비용 계산용)

| 구분 | 내 캐릭터 시뮬레이션 | 상급재련 시뮬레이션 |
|------|----------------------|----------------------|
| **소스** | `marketInfo` (거래소 캐시, `getMarketCache`) | `valueDbMap` (가치계산DB, `getValueDbData`) |
| **적용** | `adjustPrice`로 조정 후 사용 | `adjustPrice`로 조정 후 사용 |

- **내 캐릭터**: 거래소 최저가 등 **시장 시세** 기반.
- **상급재련**: **가치계산DB** 기반 (다른 로직/보정 적용 가능).

같은 재료라도 **거래소 시세 ≠ 가치계산DB**일 수 있어, **필수·보조 재료 비용**이 달라지고,  
그 결과 **총 비용(totalCost)** 과 **단위당 가치(valuePerUnit)** 도 달라집니다.

---

## 2. 실링(실링) 1개당 골드

| 구분 | 내 캐릭터 시뮬레이션 | 상급재련 시뮬레이션 |
|------|----------------------|----------------------|
| **계산** | `sillingUnitPrice` = `silverCashValue` (etc_list) **그대로** 사용 | `sillingUnitPrice` = `silverCashValue * goldPerWon` |
| **의미** | etc_list 실링 “cash” 값을 **단가로 직접** 사용 | 실링 현금가치(원) × **1원당 골드** 로 **골드 환산** |

- **상급재련**: 디스코드/크리스탈 환율 → `goldPerWon` → 실링 1개당 **골드**로 환산.
- **내 캐릭터**: `silverCashValue`를 **단가**로 쓰므로,  
  - etc_list가 **원**이면 골드가 아니라 **원** 단위가 들어가 비용 해석이 완전히 달라짐.  
  - etc_list가 **골드**로 되어 있으면, 상급재련처럼 **환율 변환**을 안 하는 차이만 남음.

그래서 **실링이 많이 들어가는 상재**에서는 **실링 처리 차이**가 결과에 크게 반영됩니다.

---

## 3. 보조재료 시세 (이득/손해 판단용)

| 구분 | 내 캐릭터 시뮬레이션 | 상급재련 시뮬레이션 |
|------|----------------------|----------------------|
| **야금술/재봉술, 숨결** | `adjustedMarketInfo[보조재료]` → **거래소 시세** | `getMaterialValue(보조재료)` → **valueDbMap** |

- **이득/손해**: `valuePerUnit > marketPrice` → “사는 게 이득” 등으로 표시.
- **내 캐릭터**: `marketPrice` = 거래소 시세.
- **상급재련**: `marketPrice` = 가치계산DB 기반 `getMaterialValue`.

같은 **valuePerUnit**이라도 **비교 대상 시세**가 다르면 **이득/손해结论**이 달라질 수 있습니다.

---

## 4. 마진 분석 로직 (공식)

- **둘 다** 아래와 같은 **시나리오 비교**로 단위당 가치를 냅니다.
  - **강화선조턴**: noAux vs **강화선조만** 사용.
  - **선조턴**: **강화선조만** vs **선조+강화선조** (마진).
  - **일반턴**: **선조+강화선조** vs **일반+선조+강화선조** (마진).
- **차이**는 **비용 계산**이 위 1~3의 **서로 다른 단가/시세**를 쓰는 것뿐입니다.

---

## 5. 요약

| 항목 | 내 캐릭터 시뮬레이션 | 상급재련 시뮬레이션 |
|------|----------------------|----------------------|
| 재료 단가 | 거래소 캐시 (`marketInfo`) | 가치계산DB (`valueDbMap`) |
| 실링 | `silverCashValue` 직접 사용 | `silverCashValue * goldPerWon` |
| 보조재료 시세 | 거래소 시세 | 가치계산DB |
| 마진 공식 | 동일 | 동일 |

**값을 맞추려면**  
- 재료 단가, 실링, 보조재료 시세를 **둘 다 같은 소스**로 통일하거나,  
- 내 캐릭터 시뮬레이션의 상재 분석만 **상급재련과 동일하게** valueDbMap + 실링 환산을 쓰도록 바꾸면 됩니다.
